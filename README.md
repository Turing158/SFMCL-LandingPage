# SFMCL-T 项目展示站


## 开发与构建

```powershell
npm install
npm run dev
npm run build
npm run preview
```

开发地址：`http://127.0.0.1:1174/`。生产文件输出到 `dist/`，可以部署至静态托管服务。使用 HashRouter，子页面刷新不需要服务器路由重写。

## 页面

- 首页：滚轮驱动的九屏演示，依次展示软件预览、技术与平台、功能拼贴、整合包、加载器、资源中心、三步上手、FAQ、下载与页脚。
- 下载：Windows x64 / x86、安装版 / 单文件版选择。
- 使用文档：根据原项目 README 整理的中文上手指南，按 8 个主题拆分为 `docs/` 下的独立 Markdown 文件。页面通过 `src/docs.ts` 读取文档，修改对应 `.md` 文件即可更新正文与目录标题。每次显示一篇文档，点击目录通过淡出、滑动入场动画切换；切换时目录与页面介绍保持原位，仅更新选中高亮，不重新播放整页入场或自动回到页首。目录采用像素边框、主题背景和阴影形成悬浮卡片，桌面初始位置下移 28px，滚动时停靠在顶部导航下方；移动端同样支持停靠，短屏可以在目录内滚动。独立地址如 `/#/docs/accounts` 支持刷新、前进和后退，旧的 `/#/docs#accounts` 地址也可打开对应文档。
- 更新日志：读取项目 GitHub Releases。

首页使用固定舞台呈现每一屏。滚轮向下进入下一屏，向上返回上一屏；桌面右侧章节导航支持直接切换，宽度在 700px 及以下时导航移到底部横向排列，窄屏可左右滑动并自动显示当前章节。手机支持上下滑动，键盘支持方向键、PageUp / PageDown、Home / End。每次切换先让当前屏的标题、图示、整张卡片和按钮沿独立的弧线、像素折线、旋转或斜向路径退场，再让下一屏的元素错峰入场。按本项目要求，始终播放完整动画，不根据系统的减少动态效果设置降级。九屏通过精简文案、次要标签和小屏图示适配视口，滚轮及触屏手势直接切换章节；连续滚轮惯性不会跳过多个章节。FAQ 每次展开一个问题，下载屏使用精简页脚。章节地址支持刷新与直接访问，例如 `/#/#resources`。

切屏控制和路径编排位于 `src/HomeDeck.tsx`，各屏布局与响应式规则位于 `src/home-deck.css`。卡片以整体沿路径进出，背景、文字、图标一起移动和渐隐；转场期间暂停内部装饰动画。各屏组件持续挂载，保留主题选择、资源分类、FAQ 展开状态和软件预览实例；隐藏屏使用 inert 与 aria-hidden 排除交互，并暂停 CSS 动画。首页专属设计规则见 `design-system/pages/home.md`。

软件完整界面仅在首页第一屏出现，切屏时沿路径退场；后续屏使用独立的图示与布局。首屏通过独立 iframe 运行 SFMCL-T 原版 React 前端，以 1120×640 的软件窗口尺寸渲染后等比缩放。导航、像素控件、设置、角色预览与组件弹窗均复用原项目。点击软件标题栏的最大化控件可在保持当前界面实例与状态的情况下放大，按 Escape 或点击遮罩可关闭；软件内部有弹窗时，Escape 优先关闭内部弹窗。软件放大时暂停官网切屏，内部滚动到边界后通过展示站适配层交给首页。

首屏在宽度小于 1100px 时采用上下布局，收紧上方文案的间距，640px 及以上将标题排成一行。软件预览按舞台的实际剩余高度和可用宽度等比放大，保留外框和导航空间；窗口尺寸、文案高度变化时自动重新计算。

`embed/sfmcl-ui/src/` 的 149 个前端文件由原项目直接同步，未修改组件或 CSS。`embed/sfmcl-ui/bridge.ts` 提供内存中的演示数据与浏览器 IPC 适配：账号登录、游戏启动、版本安装与修复、资源下载、文件选择、本地数据操作和更新检查均返回成功状态，相关列表与任务同步更新。展示区不再显示“需要桌面应用”的限制提示。所有操作仅修改当前预览的内存数据，不进行真实授权、文件读写或游戏启动；刷新后恢复初始数据。官网主题同步不会重新加载 iframe；展示区支持软件内部滚动，到达边界后将滚轮交给网页。

软件预览忽略拖入的整合包、文件和链接，不显示导入占位遮罩，也不跳转到外置登录或拖入的地址。这些拖入行为在展示站适配层拦截，原版软件组件保持不变。

“让启动器，也像你”卡片使用软件实际的主世界、地狱、末地和筛界配色，并随网站浅色、深色主题切换对应色值。图示由 CSS 绘制的像素色板组成，点击色块可同步预览主题颜色与名称。

加载器区使用不可点击的像素卡片，细绳穿过卡片顶部中央的孔洞，卡片绕孔洞轻微摆动。所有屏幕尺寸均保持单行，持续向左无缝循环，右侧接续出现后续卡片；重复的视觉队列对辅助技术隐藏。切屏时整条队列连同细绳一起沿同一路径进出，转场期间暂停内部滚动和摆动，结束后从原位置继续。

鼠标悬停加载器卡片时，整列暂停移动，当前卡片绕穿孔平滑歪斜。鼠标移开后，卡片复位，队列从暂停的位置继续向左移动。

整合包展示基于同级 `SFMCL-ps-astra` 的像素轨道、浮动卡片、动态箱子、配色与动画，文案及小屏图示已精简以适配单屏。组件位于 `src/ImportedModpack.tsx`，原版局部样式限定在 `.astra-modpack` 内，单屏适配规则位于 `src/home-deck.css`；箱子 GIF 与素材来源记录位于 `public/assets/wiki/`。

更新原项目后可以再次执行：

```powershell
npm run sync:launcher
# 或指定其他源项目路径：
npm run sync:launcher -- --source D:/EducationalData/rust/SFMCL-T/SFMCL-T
```

同步脚本只读取原项目，更新本展示站的组件与公开素材。`embed/sfmcl-ui/source-manifest.json` 记录每个前端文件的 SHA-256，可核查复制一致性。

下载与更新日志使用 `https://api.github.com/repos/Turing158/SFMCL-Transformed/releases` 提供的真实数据，不推测发布文件地址。网络失败、无发布记录或缺少所选架构的文件时，保留 GitHub Releases 入口。当前参考项目版本为 0.1.1。

## 素材与设计

软件前端、品牌图标、加载器图标及默认角色素材来自 `D:\EducationalData\rust\SFMCL-T`。软件 CSS 运行在独立 iframe 内，不受展示站样式覆盖。

展示站的 Minecraft 方块、钻石镐、橡树、森林、平原与日出使用[中文 Minecraft Wiki](https://zh.minecraft.wiki/)的真实图片，替换原先的手绘 SVG。透明物品保留无损 PNG，风景按展示尺寸压缩为 WebP，并使用延迟加载。图片位于 `public/assets/minecraft-wiki/`；每张图片的说明页、原图地址、尺寸和 SHA-256 见该目录的 `sources.json`。Minecraft 游戏素材及截图的著作权属于 Mojang Studios，不包含在展示站的 MIT 代码许可中。导航、设置等功能图标继续使用 Lucide。

资源区的四个分类、每类三张项目卡片采用 `D:/EducationalData/project-show/SFMCL-ps-astra` 的对应项目名称、简介、标签、图标、底色和 Modrinth 链接。`public/assets/resource-*.png` 的 12 张图标从该项目原样复制，来源为 Modrinth 公开项目 API，仅用于介绍并链接对应社区项目；品牌与图标权利归相应项目或权利人所有。素材来源记录见来源项目的 `ASSETS.md`。

Pixelify Sans 字体来自原项目，许可见 `public/assets/PixelifySans-OFL.txt`。设计规则保存在 `design-system/MASTER.md`。页面支持浅色与深色主题、键盘操作和移动端布局。展示站增加了错峰入场、滚动出现、像素粒子与方块浮动、按钮与卡片悬停、内容切换、FAQ 和预览弹窗动画；软件内部前端保持原样。

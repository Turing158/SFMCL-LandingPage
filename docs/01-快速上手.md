# 快速上手

1. **下载并打开启动器。** 在[下载页](/download)选择适合系统的安装版或单文件版。安装版可引导安装 WebView2；单文件版需要系统已安装该环境。
2. **添加一个角色。** 进入「角色管理 → 登录」，选择 Microsoft、离线或第三方登录方式。
3. **准备游戏版本。** 在「版本管理」添加游戏目录，安装 Minecraft 与需要的加载器，也可导入已有整合包。
4. **配置 Java，开始游戏。** 在「设置」中扫描或添加 Java，确认角色和版本，然后点击开始游戏。

> Minecraft Java 版所需的 Java 需自行准备。不同游戏版本要求不同运行环境，请根据所选版本确认。

# 角色与登录

在「角色管理」点击「登录」，选择登录方式。你可以添加多个角色，并在开始游戏前切换当前身份。

| 登录方式 | 使用说明 |
| --- | --- |
| Microsoft | 使用设备授权完成登录。正版角色支持上传或重置皮肤、切换已有的官方披风，以及修改游戏名。 |
| 离线角色 | 添加本地角色，适用于单人游戏或允许该登录方式的服务器。 |
| LittleSkin | 通过浏览器完成 OAuth 设备授权；多个角色时可选择要添加的角色。 |
| 第三方 Yggdrasil | 填写验证站点、账号与密码。支持兼容 authlib-injector 的验证服务。 |

第三方角色不能代替 Microsoft 正版认证。第三方皮肤、披风与名称请在验证站点修改后刷新同步。

# Java 与启动设置

在「设置 → 全局设置」中扫描系统已有的 Java，或手动添加 `java.exe` / `javaw.exe`。启动器会探测 Java 的版本与架构，自动选择时根据游戏要求匹配环境。扫描或手动添加后的列表会立即保存。

| 游戏示例 | 常用 Java 版本 |
| --- | --- |
| Minecraft 1.12.2 / LiteLoader | Java 8 |
| Minecraft 1.20.1 | Java 17 |
| 较新的 Minecraft 版本 | 根据版本元数据选择，通常需要 Java 21 等环境 |

还可以配置内存、游戏目录隔离、窗口大小与启动参数。每个版本的四组游戏设置可分别使用独立配置或跟随全局，修改会自动保存，详见[版本与游戏目录](/docs/versions)。

## 游戏多开与进程管理

1. **启动第一个游戏。** 确认当前角色与版本，在首页底部点击「开始游戏」。
2. **继续启动另一实例。** 第一个游戏运行后点击「继续启动」，将它收起到进程列表。再选择角色与版本，点击「开始游戏」。也可以在版本管理中切换版本，原游戏会自动收起并继续运行。
3. **查看运行中的游戏。** 点击启动区的「展开」，查看收起的游戏及启动时间。点击游戏卡片可将其恢复到主启动区；收起列表不会结束游戏。
4. **结束指定游戏。** 在主启动区点击「结束游戏」，或在进程卡片右侧点击结束按钮。其他游戏继续运行。

启动准备期间请等待当前流程完成；游戏文件下载暂停或失败时，先继续或重试对应下载，再进行后续操作。

## 退出与恢复启动器

Windows 下，游戏由独立的 `MinecraftHost` 后台进程管理。退出启动器后，已经启动的 Minecraft 会继续运行；重新打开启动器会识别仍在运行的游戏，并恢复日志查看和结束游戏操作。窗口标题、窗口位置记忆及运行中版本的删除保护也会继续保持。

> 启动器提供的联机会话会在退出时结束，正在使用该会话的游戏可能断线。联机期间请保持 Minecraft 与启动器运行；迁移、备份或还原本地数据前，仍需结束所有游戏与其他任务。

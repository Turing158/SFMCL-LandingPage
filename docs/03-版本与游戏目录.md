# 版本与游戏目录

在「版本管理」添加游戏所在的外层文件夹，启动器会使用其中的 `.minecraft/`。直接选择已有的 `.minecraft` 目录也能识别。

你可以搜索与收藏版本，使用卡片或列表视图，以及按版本覆盖全局游戏设置。开启目录隔离后，模组与存档使用对应版本的独立目录。

首页底部的「切换版本」会打开本地版本选择面板，可搜索版本名、加载器与 Java 版本；启用全部目录显示时，还可按目录名称筛选并跨目录选择。

```text
.minecraft/
├── assets/
├── libraries/
└── versions/
    └── 你的版本/
        ├── mods/
        └── saves/
```

## 按版本配置游戏

进入「版本管理 → 游戏设置」，Java、内存与游戏目录、游戏窗口、高级启动参数这四组配置可以分别选择「全局」或「独立」。切回全局后，原来的独立值仍会保留，再次开启独立即可恢复。

版本设置保存在对应目录的 `.tmcl/settings.json`，不同目录下的同名版本互不影响。运行中的版本受到删除保护；删除前先结束对应游戏。多个游戏的切换与结束操作见[Java 与启动设置](/docs/java)。

> 备份时请同时保留启动器配置与游戏目录。游戏文件始终保存在你选择的本地路径中。

# 联机教程

在启动器侧栏点击「联机」（位于「版本管理」下方），选择「官方」或「自定义」。房主负责开放世界、创建房间并分享邀请码，好友通过邀请码加入。

| 联机方式 | 房主需要准备 | 好友使用的邀请码 |
| --- | --- | --- |
| 官方联机 | 房间名称、游戏端口 | 8 位英文字母或数字，例如 `A1B2-C3D4` |
| 自定义：Cloudflare Tunnel + 本机 EasyTier | 房间名称、游戏端口，由启动器自动创建临时入口 | 以 `SFMCL2.` 开头的完整长邀请码 |
| 自定义：共享 EasyTier 节点 | 房间名称、游戏端口、可用的共享节点地址 | 以 `SFMCL1.` 开头的完整长邀请码 |

## 联机前的准备

1. **统一游戏环境。** 房主和好友准备相同的 Minecraft Java 版版本。使用整合包时，也要统一加载器、模组与必要配置；可参考[导入整合包](/docs/modpacks)。
2. **选好角色。** 在「角色管理」选择用于联机的角色，好友之间使用不同的角色名。需要离线角色加入时，先按本文的「离线角色联机」说明设置房主游戏。
3. **房主开放世界。** 通过启动器启动 Minecraft，进入单人存档，按 `Esc` 选择「对局域网开放」，完成设置并开始局域网世界。记下游戏提示的端口，例如 `51234`；每次重新开放时都要确认当前端口。
4. **准备联机组件。** 「联机」页面提示缺少组件时，点击「准备组件」，等待下载与校验完成。下载进度可在下载中心查看。房主和好友都需要准备组件。官方下载页面：[EasyTier](https://github.com/EasyTier/EasyTier/releases)、[Cloudflare Tunnel（cloudflared）](https://github.com/cloudflare/cloudflared/releases)。

> 「游戏端口」填写房主这次对局域网开放后显示的端口。共享节点地址中的端口属于 EasyTier 节点，两者用途不同，分别按游戏提示和节点提供者的说明填写。

## 官方联机

官方模式由服务提供节点与房间查询，房主无需填写共享节点地址。

### 房主创建房间

1. 选择「官方 → 创建房间」。同时运行多个游戏时，先在「房主游戏」中选中用于联机的那一个。
2. 填写「房间名称」与「游戏端口」，点击「检查端口」，确认世界已开放。
3. 点击「创建房间」，等待状态显示「世界已开放」。
4. 点击「复制邀请码」，把 8 位邀请码发给好友。界面会将其显示为两组，例如 `A1B2-C3D4`。

联机期间保持房主的 Minecraft 和启动器运行。切换启动器页面不会中断房间；结束时点击「关闭房间」，该邀请码会注销。退出启动器也会结束本实例的联机会话。

### 好友加入房间

1. 选择「官方 → 加入房间」，输入或粘贴房主提供的 8 位邀请码。带有分隔符的 `A1B2-C3D4` 可直接粘贴，小写字母会自动转为大写。
2. 点击「查看房间」，核对房间名称与游戏版本，再点击「加入房间」。
3. 等待世界与网络就绪，选好角色和对应版本，点击「启动并连接」。
4. 游戏已经运行时，点击「复制地址」，在 Minecraft 的「多人游戏 → 直接连接」中粘贴本机连接地址。请使用自己启动器显示的地址。

结束时点击「离开房间」，会结束自己的联机会话，房主的房间仍可供其他好友使用。若提示房间不存在、已关闭或已过期，请向房主获取重新创建后的邀请码。

## 自定义联机

自定义提供两种连接方式，均使用完整长邀请码。好友在「自定义 → 加入房间」粘贴邀请码，启动器会读取其中的连接方式与节点信息。

### 方法一：Cloudflare Tunnel + 本机 EasyTier

适合没有现成共享节点地址的房主。启动器在房主电脑上运行 EasyTier，并自动创建 Cloudflare 临时隧道入口。

1. 选择「自定义 → 创建房间」，填写房间名称和局域网游戏端口。多个游戏运行时，选好「房主游戏」。
2. 在「联机方式」下拉框选择「Cloudflare Tunnel + 本机EasyTier」（自定义模式的默认选项），无需填写共享节点地址。
3. 点击「检查端口」，再点击「创建房间」，等待隧道、网络与世界就绪。
4. 点击「复制邀请码」，将以 `SFMCL2.` 开头的完整内容发给好友。好友按下方「好友加入自定义房间」的步骤连接。

临时隧道依赖房主电脑和网络持续运行。关闭房间后再次创建时，请复制新的邀请码发给好友。

### 方法二：共享 EasyTier 节点

适合已经有可用 EasyTier 共享节点的房主。先向节点提供者获取完整地址，确认房主和好友的网络都能访问该节点。

1. 选择「自定义 → 创建房间」，填写房间名称与局域网游戏端口。多个游戏运行时，选好「房主游戏」。
2. 在「联机方式」下拉框选择「共享EasyTier节点」。
3. 在下拉框左侧的「共享节点」输入框中填写节点地址，保留协议前缀，并按节点要求填写端口。
4. 点击「检查端口」，再点击「创建房间」，等待世界与网络就绪。
5. 点击「复制邀请码」，将以 `SFMCL1.` 开头的完整内容发给好友。好友按下方步骤连接，无需另外填写节点地址。

支持的节点地址格式如下。表中的域名与端口仅演示格式，请替换为节点提供者给出的实际值。

| 节点协议 | 地址格式示例 | 端口说明 |
| --- | --- | --- |
| TCP | `tcp://node.example.com:11010` | 必须明确填写节点端口 |
| UDP | `udp://node.example.com:11010` | 必须明确填写节点端口 |
| WSS | `wss://node.example.com` 或 `wss://node.example.com:443` | 未填写端口时默认使用 `443` |

> 即使在共享节点输入框填入官方中继地址，房间仍属于「自定义」，使用 `SFMCL1.` 长邀请码。好友需要在「自定义」页面加入。

### 好友加入自定义房间

1. 选择「自定义 → 加入房间」，粘贴房主发送的完整长邀请码，包括开头的 `SFMCL1.` 或 `SFMCL2.`，请勿截断或修改。
2. 点击「查看房间」，核对房间名称、游戏版本与联机入口，再点击「加入房间」。
3. 等待世界与网络就绪，选择对应的角色和版本，点击「启动并连接」。
4. 游戏已经运行时，点击「复制地址」，在「多人游戏 → 直接连接」中粘贴自己启动器显示的本机连接地址。

结束时，房主点击「关闭房间」，好友点击「离开房间」。联机期间，房主需要持续运行 Minecraft 与启动器。

## 离线角色联机

房主需要允许离线角色进入时，在「创建房间」按钮同一行的最右侧打开「离线联机」。更改后必须重启房主的 Minecraft，再进入存档并对局域网开放，使用新的游戏端口创建房间。

仅切换角色或重新创建网络房间不会让设置在正在运行的游戏中生效。各好友应使用不同的角色名；关闭「离线联机」后也需要重启游戏才能恢复原有认证。

该选项作用于原版单人世界的内置服务器。当前已验证原版 `26.3` 的登录握手；缺少官方映射的旧版及 Fabric / Forge / Quilt / NeoForge 加载器暂不支持开启该选项，启动时会明确提示。连接外部服务器时仍需遵守服务器的账号认证要求。

## 常见问题

| 遇到的情况 | 处理方式 |
| --- | --- |
| 检查端口失败，或一直显示「等待世界开放」 | 确认房主已进入存档并对局域网开放，填写本次游戏提示的端口；多个游戏运行时核对「房主游戏」。 |
| 邀请码无法查看房间 | 官方短码在「官方」输入，自定义长码在「自定义」完整粘贴；房间关闭或重新创建后向房主获取新邀请码。 |
| 官方服务暂不可用 | 稍后重试，也可由房主改用自定义方式创建新房间，把新的长邀请码发给好友。 |
| 网络连接超时 | 确认房主的游戏与启动器仍在运行，并检查所用共享节点或 Cloudflare 隧道的可达性；根据页面提示重试。 |
| 加入后无法进入游戏 | 先核对双方的 Minecraft 版本、加载器与模组；离线角色再确认房主已启用「离线联机」并重启游戏。 |
| 下载组件失败 | 在下载中心查看错误并重试；也可使用「导入组件」选择符合启动器校验要求的组件 ZIP 包。 |

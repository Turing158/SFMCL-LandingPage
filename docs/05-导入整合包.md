# 导入整合包

在「资源中心 → 整合包」选好 Modrinth 或 CurseForge 来源，按中文名、原名或别名搜索项目。选定文件后，点击「安装整合包」创建实例，或选择「下载到文件夹」只保存整合包。

已有本地文件时，进入「版本管理 → 导入整合包」选择压缩包或客户端目录，也可以直接拖入桌面窗口。识别成功后，安装预览会并列显示词库中匹配到的中文名与原名。「游戏名称」默认根据原名和版本生成，可以自行修改。

在「安装目录」选择已有游戏目录，也可以点击旁边的「＋」添加目录。选择已登记的目录会直接选中它。确认游戏名称、目录及可选文件后，点击「开始安装」。

支持的文件格式：`MRPACK`、`ZIP`、`7Z`、`RAR`、`TAR`、`TAR.GZ`。

支持 Modrinth、CurseForge、MCBBS、MultiMC / Prism 清单与完整客户端目录。整合包默认使用独立游戏目录。安装时启动器会并行解析依赖，文件下载进度可在下载中心查看。

服务端包、加密或多卷压缩包、不兼容的自定义补丁等会提示具体原因。安装结束后会清理临时文件和关联的下载记录。安装失败或取消时也会清理临时实例。

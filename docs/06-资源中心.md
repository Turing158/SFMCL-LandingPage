# 资源中心

搜索模组、材质包、光影、数据包与整合包，按版本和分类筛选，查看项目详情、文件版本与前置依赖。

## 用中文名查找模组和整合包

在「资源中心」选择「模组」或「整合包」，选好 Modrinth 或 CurseForge 来源，输入名称后按 Enter 或点击搜索按钮。例如，在模组中搜索「钠」可以找到 Sodium，在整合包中搜索「难以置信的优化」可以找到 Fabulously Optimized。

匹配到词库的项目会同时显示中文名和原名，未收录的项目保留原名。含汉字的名称或别名会先匹配词库，纯英文名称和缩写由所选平台搜索。本地模组列表也支持按词库别名筛选。名称数据来自 HMCL 整理的 MC 百科词库，可在「设置 → 关于」查看致谢。

## 查看和调整下载

下载任务统一进入下载中心，可查看进度与日志，暂停、继续或重试。CurseForge 文件需要手动下载时，可在文件详情中补选已下载文件，通过校验后继续。

「设置 → 启动器设置 → 下载 → 下载源策略」提供「速度优先（推荐）」「官网优先」和「镜像优先」。速度优先会自动测速并选择较快的可用源；下载失败或校验不通过时会尝试备用源，文件校验仍会执行。

在同一设置区可以调整「同时下载数」（1–32）。有文件排队时，调高上限可以立即开始更多下载。调低上限后，正在传输的文件会先完成，后续文件按新上限开始，无需暂停或重启任务。

侧栏下载任务以环形图标和状态文字显示进度，点击可进入下载中心。侧栏显示方式可设为「下载时」「始终」或「关闭」。关闭启动器时会暂停并保存下载任务，整合包安装中断后需要重新发起安装。

> 数据包下载后，需要放到目标世界存档的 `datapacks/` 目录。资源的运行条件请以项目详情为准。
